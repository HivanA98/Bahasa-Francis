## D. Tabel konjugasi

**avoir** (mempunyai) — model irregulier

| Kata ganti | Bentuk |
|:-----------|:-------|
| je | j'ai |
| tu | tu as |
| il / elle / on | il / elle / on a |
| nous | nous avons |
| vous | vous avez |
| ils / elles | ils / elles ont |

Catatan: Tak beraturan dan sangat sering dipakai. Bentuk je-nya dimulai dengan vokal sehingga selalu menjadi j'ai.

**parler** (berbicara) — model er

| Kata ganti | Bentuk |
|:-----------|:-------|
| je | je parle |
| tu | tu parles |
| il / elle / on | il / elle / on parle |
| nous | nous parlons |
| vous | vous parlez |
| ils / elles | ils / elles parlent |

## E. Tata bahasa

1. **a** — -tion
   La nation, la question, la situation. Sedangkan -ment (le moment), -eau (le bureau), dan -isme (le tourisme) biasanya maskulin.
   (topik g01: Gender kata benda: maskulin dan feminin)

2. **a** — voiture
   La voiture. Tiga lainnya maskulin: le livre, le sac, le fromage.
   (topik g01: Gender kata benda: maskulin dan feminin)

3. **a** — Kata benda Bahasa Prancis hampir selalu memerlukan artikel
   Harus « j'aime le café ». Bahasa Indonesia bisa berdiri tanpa artikel, Bahasa Prancis tidak. Bentuk j'aime memang tanpa -s karena pelakunya je.
   (topik g02: Artikel takrif: le, la, l', les)

4. **a** — l'
   L'école. Di depan bunyi vokal, le dan la sama-sama menjadi l'; gendernya baru terlihat pada kata sifatnya.
   (topik g02: Artikel takrif: le, la, l', les)

5. **a** — Le livre berarti buku, la livre berarti setengah kilogram
   Dua kata berbeda yang kebetulan ditulis sama; gendernya yang membedakan arti. Bentuk jamaknya les livres untuk keduanya.
   (topik g01: Gender kata benda: maskulin dan feminin)

## F. Pelafalan

1. **petit** = /pəti/ (pë-ti) — kecil
   Huruf t di akhir tidak dibunyikan, dan e tanpa aksen di suku pertama dibunyikan /ə/. Bentuk feminin petite barulah /pətit/.
